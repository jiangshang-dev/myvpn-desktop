# MyVPN 网络连接与设备管理平台

MyVPN 是一个面向 **网络编程学习、自托管网络环境及企业内部网络管理** 的开源客户端与设备管控示例项目。

项目采用：

* Spring Boot
* MySQL
* Redis
* Vue 3
* Electron

实现桌面客户端、服务端 API 与管理后台之间的完整交互流程，可用于学习和研究客户端身份认证、设备管理、节点配置、连接会话、在线状态、心跳检测和远程会话控制等技术。

## 项目定位

本项目主要用于以下场景：

* 计算机网络及客户端开发学习
* 企业内部网络连接管理
* 实验室、测试环境网络管理
* 自有服务器和自有网络环境的连接管理
* Electron + Spring Boot 前后端项目实践
* 用户、设备、节点及会话管理功能研究

本项目 **不提供任何公共网络节点、服务器资源、网络线路或商业网络接入服务**。

项目运行所需的网络基础设施、服务器及连接参数均由使用者自行准备，并应确保其拥有合法使用权限且符合所在地法律法规。

## 项目功能

### 桌面客户端

支持：

* 用户注册与登录
* 设备身份识别
* 网络节点列表获取
* 连接状态管理
* 在线心跳
* 网络速度及流量状态上报
* 主动断开连接
* 接收服务端会话终止指令

### 管理后台

支持：

* 用户管理
* 设备管理
* 在线设备查看
* 会话管理
* 节点配置管理
* 在线状态统计
* 强制结束客户端会话
* 用户及设备启用/禁用

### 服务端

服务端负责：

* 用户身份认证
* 设备状态管理
* 网络配置管理
* 会话生命周期管理
* Redis 在线状态维护
* 客户端心跳处理
* 管理后台 API

## 网络连接说明

本项目主要实现网络客户端与管理平台之间的 **控制层和管理层功能**。

具体的数据传输、隧道协议以及网络核心程序不属于本项目提供的公共网络服务。

如果使用者需要接入第三方或自建的网络核心，应自行完成相关组件部署与配置，并确保：

1. 对服务器及网络资源具有合法使用权限；
2. 使用场景符合服务器所在地及使用者所在地法律法规；
3. 不利用本项目从事未经授权的网络访问、网络攻击或其他违法活动。

项目仓库默认不提供：

* 公共网络节点
* 可直接使用的服务器地址
* 公共账号
* 网络线路
* 商业订阅服务
* 网络接入服务

## 客户端流程

```text
登录
 ↓
设备认证
 ↓
获取可用配置
 ↓
建立客户端会话
 ↓
在线心跳
 ↓
状态与流量上报
 ↓
结束会话
```

管理员可以通过管理后台查看用户、设备及会话状态，并对客户端会话进行管理。

## 安全说明

生产或真实网络环境部署前，请至少完成以下安全配置：

* 修改默认管理员账号和密码
* 使用环境变量保存数据库密码
* 使用环境变量保存 Redis 密码
* 不要将服务器密钥、Token、UUID 等敏感信息提交到 Git
* 服务端 API 使用 HTTPS
* 管理后台限制公网访问范围
* 设置合理的认证和权限控制
* 定期更新依赖并检查安全漏洞

请勿在公开仓库中提交真实服务器地址、访问凭据、私钥、Token 或其他敏感配置。
